# Lua 登录期权限绑定（Authentik claims → kamc 权限）

## 核心设计

**挂钩点**：三个 JWT 签发入口（`/auth/callback`、`/auth/token-exchange`、`/auth/dev-token`）在提取 claims 之后、签发 JWT 之前**同步执行**启用的脚本；**fail-closed**——任何脚本错误拒绝登录（403 + 审计告警），管理员可禁用脚本恢复。数据面请求不执行（零性能损耗）。另提供管理员手动执行端点（可注入 mock claims、支持 dry-run）测试脚本。

**脚本形态**：多个命名脚本（PG 存储，按 name 排序执行），admin API 全生命周期管理，保存时做 Lua 语法编译校验。

**kamc API 桥接**：用 gopher-lua 的原生 Go 函数注册（非 HTTP 自调用，无凭证回环问题），只暴露安全子集：

```lua
-- 入参（全局表）：claims = {sub, email, groups={...}}
-- 桥接 API（幂等操作返回 bool）：
--   kamc.list_clusters() / kamc.cluster_exists(dom)
--   kamc.list_bindings(dom) / kamc.add_binding(user, role, dom) / kamc.remove_binding(user, role, dom)
--   kamc.has_policy(sub, dom, obj, act) / kamc.add_policy(sub, dom, obj, act) / kamc.remove_policy(...)
--   kamc.list_policies()
-- 示例（用户场景：按 Authentik 组绑定角色，组对应角色不存在则新建）：
for _, g in ipairs(claims.groups) do
  if g == "authentik-devs" then
    if not kamc.has_policy("role:devs", "cluster-a", "dev/*", "get|list|watch") then
      kamc.add_policy("role:devs", "cluster-a", "dev/*", "get|list|watch")   -- "组不存在则新建"
    end
    kamc.add_binding(claims.sub, "role:devs", "cluster-a")
  end
end
```

桥接直接调 `authz.Enforcer`（增删自动触发跨副本广播）与 dao 的集群读取；**刻意不暴露** Token 签发、用户踢出、集群删除等危险操作。

**沙箱**（纵深防御；脚本是管理员写的，但不信任其内容）：`gopher-lua`（纯 Go Lua 5.1）`SkipOpenLibs` 后仅开 table/string/math，base 库剥离 `load/loadstring/dofile/require`，不注入 os/io；每脚本独立 LState + 执行超时（2s，超时按失败处理；gopher-lua 无抢占式中断，卡死脚本泄漏一个 goroutine 属已知限制，文档注明）。

**dry-run**：手动执行端点带 `?dry_run=1` 时桥接只记录动作不落地，返回动作清单——管理员改脚本的验证闭环。
